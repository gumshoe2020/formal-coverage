# Build record

These specifications, prompts and implementation logs are the build record of
formal-coverage. They are retained so readers can audit how the tool was built;
historical entries describe the policy and evidence available at the time.

The [release plan](PLAN-RELEASE.md) governs v1.4.1. [PROGRESS](PROGRESS.md) records
local acceptance checks, and [NOTES](NOTES.md) records decisions and limitations.
Machine-specific paths and private references have been replaced with portable
placeholders. See the [public README](../README.md) and [evidence contract](../docs/evidence.md)
for current behavior and reproduction instructions.
